# 个人技术网站 — 内容设计文档

## 1. 网站定位

一个面向技术招聘者的个人作品集网站。目标是让招聘者在 2-3 分钟内了解：
- 我是谁、做什么方向
- 我会什么技术、深度如何
- 我做过什么项目（有可验证的代码）
- 我的学习能力和竞赛成绩

## 2. 页面结构

### 首页 Home `/`

**核心目标：** 第一眼留下印象，引导到项目和简历

内容区块：
1. **终端窗口**（签名组件）
   - `$ whoami` → 姓名
   - `$ skills` → Python Django MySQL Linux ...
   - `$ status` → Looking for opportunities
   - 闪烁光标收尾

2. **个人标题**
   - 主标题：你好，我是张以勒
   - 副标题：计算机科学与技术背景
   - 描述：专注于 Python 开发、人工智能应用和数据分析方向
   - 标语（英文）：Building software with Python, AI and cloud technologies

3. **行动按钮**
   - 查看项目 → 跳转 /projects
   - 下载简历 → 跳转 /resume

4. **技术标签云**
   - Python Django MySQL Linux Docker Hadoop AI Data Analysis

5. **状态指示**
   - 绿色脉冲点 + "目前正在寻找开发岗位机会"

6. **亮点数字**
   - 2 完成项目 · 7 竞赛奖项 · 4 技术方向 · 2022 开始编程

7. **精选项目**
   - 自动展示 projects 列表第一个项目（名称、分类、摘要、标签、链接）

| 数据类型 | 用途 | 说明 |

| **博客文章** | Blog 页面 | 目前导航有 Blog 链接但无内容。建议写 3-5 篇技术成长记录 |

## 5. 页面内容优先级

**P0 - 求职核心（招聘者必看）：**
- 首页（快速建立印象）
- 项目页（证明工程能力）
- 竞赛页（证明学习能力）
- 简历页（完整信息）

**P1 - 辅助了解：**
- 关于页（个人背景）
- 技能页（技术栈一览）

**P2 - 扩展内容（可后续补充）：**
- 联系页（已经可用）
- 博客页（暂无内容）
